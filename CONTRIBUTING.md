# Contributing

Thanks for looking. last-job-search has one maintainer, and the most useful thing you can
send is an issue.

**Found a bug, or have an idea?** [Open an issue](https://github.com/aranculleton/last-job-search/issues/new/choose).
Say what you asked it to do, what you expected and what happened. For a posting that was
scored or screened wrongly, the posting's link and the score it got are usually enough.
Never paste anything personal: the app's tracker is public.

**Pull requests.** Outside pull requests are not merged, and the reason is not you: every
change has to pass a scan against the maintainer's own private data before it can be made
public, and that scan only runs on the maintainer's side. If you have a fix, put it in an
issue (a diff, or a link to your branch) and it will be brought in, with credit in the
changelog.

**Running it in another agent tool?** Forks that adapt it to Codex, Gemini CLI, Cursor or
anything else are welcome. Open an issue with the link and it will be listed.
[AGENTS.md](AGENTS.md) is the place to start.

**A security problem?** Read [SECURITY.md](SECURITY.md) first; it says how to report one.

How the app itself is built and changed is in [MAINTAINING.md](MAINTAINING.md).
